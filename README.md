# L'Atelier de Mila et Enzo

Site pour les enfants (3 à 9 ans) des Petits Papiers Faciles : histoires où l'enfant choisit la suite, coloriage magique, coloriages à imprimer et boutique des créations numériques.

Site statique (HTML/CSS), sans compilation. Adresse prévue : atelier.lespetitspapiersfaciles.fr (sous-domaine IONOS, à créer).

- `index.html` : accueil, personnages, boutique
- `histoires.html` : 3 histoires « C'est TOI qui décides »
- `coloriages.html` : l'appli de coloriage
- `a-imprimer.html` : coloriages à télécharger
